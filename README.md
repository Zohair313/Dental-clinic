# Velour Dental Clinic Web Application

A modern, responsive, and high-performance Dental Clinic web application built with **React 19**, **Vite**, and **Tailwind CSS**.

---

## 🌟 Features

- **Modern Hero Section**: Highlighting compassionate care, board-certified dental specialists, ratings, and instant booking calls-to-action.
- **Comprehensive Dental Services**: Interactive cards for General Dentistry, Teeth Whitening, Implants, Orthodontics, Pediatric Care, and Emergency relief.
- **Why Choose Us**: Highlighted clinic advantages including painless anesthesia, hospital-grade sterilization, and transparent pricing.
- **Specialist Profiles**: Dedicated doctor showcase cards with qualifications and experience.
- **Patient Reviews**: Real patient ratings and testimonials.
- **Interactive Appointment Booking Form**: Clean form with service selection, date picker, and confirmation state.
- **Emergency & Contact Information**: Address, direct phone lines, emergency contact, opening hours, and insurance network details.
- **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.

---

## 🚀 Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
